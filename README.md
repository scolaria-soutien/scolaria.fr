## Intégration GitHub Pages

1. Placer `logo.png` à la racine du repo (même dossier que index.html)
2. Les articles vont dans un dossier `/articles/` pour rester organisés
3. Mettre à jour les liens Calendly dans chaque fichier

## Lien Calendly

Remplacer `https://calendly.com/scolaria` par le vrai lien dans :
- `index.html` (ligne ~809)
- `methode-travail-3eme-brevet.html` (2 occurrences)
